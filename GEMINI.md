# Aturan dan Instruksi Proyek

## Git Workflow (Wajib)
- Setiap kali ada perintah/instruksi dari pengguna yang menghasilkan perubahan pada file atau proyek:
  1. Selalu periksa perubahan dengan `git status`.
  2. Tambahkan perubahan dengan `git add .`.
  3. Buat commit dengan pesan yang deskriptif dan jelas (`git commit -m "..."`).
  4. Selalu lakukan push ke repository GitHub (`git push origin <branch>`).
